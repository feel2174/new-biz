# 네이버 광고 키워드 추출 + 광고 소재 문구 전략

이 문서는 biz.zucca100.com에 **새 콘텐츠 페이지를 작성하거나, 기존 페이지의
주제/키워드 범위를 크게 바꿀 때마다** 참고한다. 목적은 페이지 본문 자체가 아니라,
그 페이지를 광고 계정에 태우기 위해 필요한 두 가지 부산물을 산출하는 것이다.

1. **광고 키워드 리스트** — 네이버 검색광고 계정에 키워드로 등록할지 판단하기 위한 목록.
2. **광고 소재 문구** — 파워링크 광고 등록에 쓰는 제목/설명 텍스트.

사용자가 키워드 리스트를 따로 주지 않아도, 글 주제만으로 스스로 후보 키워드를
추출해서 산출한다(리스트를 받았을 때만 작업하던 기존 방식보다 넓은 범위).

**이 문서의 산출물은 코드베이스에 저장하지 않는다.** `content/posts.json`/`LocalPost`
타입에 필드를 추가하지 않고, 매번 채팅 응답으로만 전달한다.

관련 문서:
- [`docs/content-page-playbook.md`](../docs/content-page-playbook.md) §7 —
  키워드를 A/B/C/D로 분류하는 기준 자체는 이 문서에 있다. 아래 1단계에서 그대로
  재사용하며, 여기서 다시 설명하지 않는다.
- [`AI_Copywriting_Skill_Guideline.md`](./AI_Copywriting_Skill_Guideline.md) —
  광고 소재 제목을 만들 때 쓰는 6개 카피 프레임워크. 2단계에서 엔진으로 재사용한다.

---

## 1단계 — 광고 키워드 추출

1. 글의 제목/주제/본문 핵심 섹션에서 후보 키워드를 뽑는다:
   - 핵심 키워드 1개(글의 대표 주제어)
   - 롱테일 변형 여러 개(핵심 키워드 + 방법/조회/신청/가격/후기 등 접미사)
   - 트러블슈팅성 키워드(오류/안됨/실패 등, 본문에 실제 해결 섹션이 있는 경우만)
2. 각 후보 키워드에 `docs/content-page-playbook.md` §7의 4그룹 분류를 적용한다:
   - **A. 브랜드명 없는 순수 일반어** → 등록 비추천(승인 불가)
   - **B. 브랜드+정보성 접미사 없음** → 조건부(페이지 제목에 "정보" 등 보강 필요)
   - **C. 트러블슈팅/작업형** → 본문에 전용 섹션이 있으면 등록 추천
   - **D. 검색 의도 불일치** → 등록 비추천(제외)
3. 아래 표 형식으로 정리해서 제공한다.

```
## 광고 키워드
| 키워드 | 그룹 | 판단 | 비고 |
|---|---|---|---|
| (핵심 키워드) | C | 등록 추천 | 본문 "OO 섹션"에서 실제로 다룸 |
| (일반어 변형) | A | 등록 비추천 | 브랜드명 없는 순수 일반어, 승인 불가 |
```

> 참고: `actionGuide.primaryKeyword`/`relatedKeywords`(있는 경우)는 **온페이지 SEO/
> 검색 의도 타겟팅용**이다. 이번 표의 "광고 계정 등록용 키워드"와 내용이 겹칠 수는
> 있지만 같은 개념이 아니므로 혼동하지 않는다.

---

## 2단계 — 광고 소재 문구 생성

네이버 파워링크 소재 규격(제목 15자 이내, 설명1·설명2 각 45자 이내, 표시 URL)을
기준으로 작성한다. **광고 플랫폼의 글자수 제한은 바뀔 수 있으므로, 실제 등록 전
네이버 광고관리시스템에서 최신 기준을 반드시 재확인할 것.**

- **제목안**: 3~5개를 만들되, 각각 [`AI_Copywriting_Skill_Guideline.md`](./AI_Copywriting_Skill_Guideline.md)의
  6개 프레임워크 중 최소 1개 이상을 적용한다(같은 프레임워크만 반복하지 않고 섞는다).
  15자 제한 안에서 핵심 키워드가 최대한 살아있도록 우선순위를 둔다.
- **설명1 / 설명2**: 페이지 핵심 정보 요약 + CTA 유도 문구로 구성한다. 단,
  `docs/content-page-playbook.md` §8 컴플라이언스 원칙을 광고 소재에도 동일하게
  적용한다:
  - 효능·의학적 효과 단정 금지(식품/건강)
  - "공식", "최저가", "즉시 승인", "혜택 보장" 등 미인증 표현 금지
  - 금융/보험/의료 관련 자격·심사·비용·보장범위 단정 금지
  - 광고 소재도 심사 대상이므로, 본문에서 피하는 표현은 소재 문구에서도 피한다.
- **표시 URL**: 페이지가 안내하는 실제 목적지 도메인 기준으로 제안한다
  (`docs/content-page-playbook.md`의 CTA 목적지 관례, 즉 `zucca100.com/{slug}/`와
  맞춘다).

---

## 3단계 — 산출물 전달 형식 (고정 템플릿)

새 글 작성(또는 키워드 범위가 바뀌는 개편)이 끝나면, 페이지 자체와 별개로 아래
템플릿을 채팅 응답에 포함해서 함께 제공한다.

```
## 광고 키워드
| 키워드 | 그룹 | 판단 | 비고 |
|---|---|---|---|

## 광고 소재 (네이버 파워링크)
- 제목안 1~5 (각 15자 이내)
- 설명1 / 설명2 (각 45자 이내)
- 표시 URL 제안
```

---

## 범위 밖

- `content/posts.json` / `lib/local-posts.ts`의 `LocalPost` 타입에는 이 산출물을 위한
  필드를 추가하지 않는다. 저장이 필요해지면 별도로 재검토한다.
- 트래픽 게이팅(`components/traffic/traffic-gate.tsx`)이나 내부링크 쿼리스트링
  유지(`components/cta/internal-link-query-preserver.tsx`) 로직과는 무관하다 —
  이 문서는 광고 계정/소재 산출에 관한 것이며 페이지 코드를 변경하지 않는다.
